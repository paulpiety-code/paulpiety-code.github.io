Tietosuojaseloste

Päivitetty 10.10.2026. Tämä seloste koskee henkilökohtaista CORE2 Drive Backup -varmuuskopiointityökalua ja sen Google Drive -rajapinnan käyttöä.

CORE2 Drive Backup on tarkoitettu ainoastaan sovelluksen omistajan omaan varmuuskopiointiin, ei ulkopuolisille käyttäjille tarjottavaksi palveluksi.

1. Sovelluksen tarkoitus

Sovellus kopioi omistajan Railway-palvelussa sijaitsevien SQLite-tutkimustietokantojen yhtenäisiä varmuuskopioita omistajan Google Drive -tilille. GitHub Actions suorittaa ajastetun työnkulun ja rclone siirtää tiedostot OAuth-valtuutuksen avulla.

2. Käsiteltävät tiedot ja Google API -käyttö

Google Drive API -käyttöoikeus on tarkoitettu varmuuskopiotiedostojen luomiseen ja siirtämiseen valittuun Drive-kansioon, tiedostojen olemassaolon ja tarkisteiden tarkistamiseen sekä siirron onnistumisen varmistamiseen. Käyttöoikeuden tekninen laajuus voi antaa rclone-ohjelmalle mahdollisuuden käsitellä myös muita Google Drive -tiedostoja, vaikka nykyinen työnkulku käyttää vain varmuuskopiokansiota.

Työnkulku käsittelee SQLite-varmuuskopiotiedostoja, tiedostonimiä, teknisiä tarkisteita, ajonaikaista tilatietoa ja toimintaan tarvittavia OAuth-valtuutustietoja. Sitä ei ole suunniteltu lukemaan sähköposteja, yhteystietoja tai selaushistoriaa.

3. Tiedon käyttö ja jakaminen

Tietoja käytetään vain varmuuskopiointiin, palautettavuuden tukemiseen ja siirron eheyden tarkistamiseen. Tietoja ei myydä, luovuteta mainostajille tai käytetä kohdennettuun mainontaan. Tietoja voivat teknisesti käsitellä palveluntarjoajat Google Drive, GitHub Actions ja Railway niiden omien palveluehtojen ja tietosuojakäytäntöjen mukaisesti.

4. Tallennus ja säilytysaika

Varmuuskopiot säilytetään käyttäjän omassa, käyttöoikeuksiltaan yksityisessä Google Drive -kansiossa, kunnes käyttäjä poistaa ne. GitHub Actions käyttää ajon aikaista väliaikaista tallennustilaa; epäonnistuneen siirron yhteydessä valmis varmuuskopio voidaan tallentaa GitHubin hätäartefaktiksi enintään seitsemäksi päiväksi. Työnkulun lokit voivat sisältää ei-salaisia tiedostonimiä, tietokantarivien lukumääriä ja tarkisteita. Julkiselle GitHub Pages -sivustolle ei tallenneta varmuuskopioita.

5. Turvallisuus

OAuth-valtuutustiedot ja Railway-tunnukset on tarkoitus säilyttää GitHub Actionsin salattuina salaisuuksina, ei julkisen repositorion lähdekoodissa. Varmuuskopioiden eheys tarkistetaan SQLite-tietokannan tarkistuksella sekä tiedostotarkisteilla. Kaikki ulkoiset palvelut muodostavat omat tietoturvariskinsä, eikä täydellistä riskittömyyttä voida luvata.

6. Käyttöoikeuden peruuttaminen ja tietojen poistaminen

Omistaja voi peruuttaa sovelluksen Google Drive -käyttöoikeuden Google-tilin turvallisuusasetusten kautta sekä poistaa OAuth-tunnuksen Google Cloudista ja GitHub Actionsin salatuista asetuksista. Käyttäjä voi poistaa varmuuskopiot suoraan Google Drivestä. Käyttöoikeuden peruuttaminen ei automaattisesti poista aiemmin luotuja varmuuskopioita.

7. Google API Services User Data Policy

Google API:n kautta saatujen käyttäjätietojen käyttö ja mahdollinen siirtäminen toisiin sovelluksiin noudattavat Google API Services User Data Policy -käytäntöä, mukaan lukien Limited Use -vaatimukset. Tietoja käytetään vain käyttäjän nimenomaisesti sallimaan varmuuskopiointitoimintoon.

8. Yhteydenotto

Kyseessä on henkilökohtainen ei-kaupallinen sovellus. Yhteydenotto tapahtuu Google OAuth -suostumusnäytössä ilmoitettuun käyttäjätuen sähköpostiosoitteeseen.
